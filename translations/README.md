# 翻译项目

本目录按人物整理翻译项目。同一人物目录可以同时收录该人物的一手文献和相关二手文献。项目文件的存在不表示译稿已经完成。

## 分类规则

- 一手文献通常归入原作者目录；二手文献通常归入主要研究对象目录。
- 如果二手文献的作者本身是知名哲学家，例如布兰顿评述塞拉斯、海德格尔阐释康德，应先询问仓库所有者的意见，再确定是否归入二手文献作者目录，不自动按研究对象归类。
- 如果作者不是知名哲学家，且文本也不以某位哲学家为主要研究对象，文件直接放在 translations/ 目录，不另建人物目录。
- 涉及多位哲学家、难以确定主要归属的文本，也先询问仓库所有者。
- 已确认：布兰顿的两篇塞拉斯研究归入布兰顿；《塞拉斯论康德》归入麦克道威尔；《分析哲学的起源》归入达米特；《信任的精神》与《康德关于心智、意义与理性的教诲》归入布兰顿；《休谟：经验主义与主体性》归入德勒兹。
