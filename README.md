# 哲学文本

用于整理哲学创作、译稿与阅读笔记，并保留每次修订的记录。

## 目录

| 目录 | 用途 |
| --- | --- |
| `writings/` | 原创文章、论证草稿与随笔 |
| `translations/` | 译稿、原文出处、术语表与翻译说明 |
| `notes/` | 阅读笔记、问题记录与参考文献 |
| `templates/` | 创作、翻译和笔记模板 |

## 添加一篇文本

1. 复制相应模板到对应目录，以简短标题命名，例如 `writings/论理由与责任.md`。
2. 长篇作品使用独立文件夹，按章节拆分；译稿可将术语表放在同一文件夹。
3. 每次完成一组相关修改后提交，说明改了什么，例如“补充第二节的反例”或“统一 Bedeutung 的译法”。
4. 需要讨论的问题可记录在 GitHub Issues；一次较大的修订也可以通过 Pull Request 对照审阅。

## 文本格式

建议以 UTF-8 编码的 Markdown（`.md`）保存正文。标题、脚注和公式可以直接编辑，修改记录也容易比较。Word、PDF 等排版版本可以与正文一起保存，但应注明与哪一版正文对应。

在引用和译稿中记录原文版本、页码或章节，以及可用的来源链接。阅读笔记应区分原文引述、转述和自己的解释。对尚未确定的术语或论证，保留待讨论标记。

## 版本与发布

正文开头注明状态：草稿、修订中或定稿。完成一轮重要修订后，可以添加 Git 标签，例如 `2026-10-文章短名-v1`，便于回到当时的版本。

本仓库为公开仓库，提交内容和历史修订均可能被公众查看。请仅提交你希望公开的文本。

本仓库暂不设置统一开放许可证。原创文本、译文及所引原文的权利状态需分别说明；仓库公开本身不表示统一授予转载、改编或再分发许可。
